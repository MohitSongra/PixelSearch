# PixelSearch icon

The photo frame, mountain image, pixel sun and search lens represent semantic
photo retrieval. This replaces the default Flutter Android launcher icon.

`pixelsearch_icon.png` is the final artwork created with the built-in image
generation tool on 2026-09-09. Android density/adaptive assets are generated with
`dart run flutter_launcher_icons`; only Android is enabled in the configuration.

Final design prompt: preserve the photo frame, mountains, amber sun pixel and
magnifier; use white, teal and amber on a flat dark charcoal #142124 background;
keep generous margins for launcher masks; no text, mockup, shadows or pattern.
