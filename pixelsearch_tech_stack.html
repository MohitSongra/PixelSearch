PixelSearch Android app — complete tech stack organized by layer

Core framework the app itself
Flutter 3.x
Android-first, iOS-ready. Single Dart codebase compiles to native ARM.
flutter SDK
Dart 3
Language. Null-safe, async/await, isolates for heavy background work.
dart SDK
Riverpod 2
State management. Providers for async data, notifiers for UI state.
flutter_riverpod
AI / ML models on-device inference
MobileCLIP-S1 / S2
Apple's mobile-optimised CLIP variant. Converts images and text queries into the same 512-dim embedding space so they can be compared directly. The core of all semantic search.
exported to ONNX → onnxruntime_flutter
on-device core model
CLIP ViT-B/32 (fallback)
OpenAI's original CLIP model, also ONNX-exported. Used if MobileCLIP accuracy needs a boost, or for benchmark comparison. Same 512-dim output.
openai/CLIP → ONNX
on-device
Google ML Kit — Image Labeling
Runs on-device at index time. Generates object/scene tags per photo (e.g. beach, food, dog). These tags boost keyword recall in hybrid search alongside CLIP vectors.
google_mlkit_image_labeling
on-device
Google ML Kit — Face Detection
Detects faces in photos at index time. Sets the has_faces flag in SQLite. Used for face-presence filter. Full face clustering is a stretch goal.
google_mlkit_face_detection
on-device stretch
Whisper.cpp (optional)
On-device speech-to-text for voice search. The tiny or base model runs locally — no audio leaves the phone. Transcribed text feeds into the normal CLIP search pipeline.
whisper_flutter_new
on-device post-MVP
GPT-4o Vision / Gemini Vision
Cloud caption generation. User selects photos, sees consent prompt, confirms upload. Caption returned, stored locally, never re-uploaded. Used to improve BM25 recall.
http + OpenAI / Google API
cloud opt-in
Search & vector engine the retrieval core
Brute-force cosine (Dart isolate)
MVP search: load all 512-dim BLOB vectors from SQLite into memory in a background isolate, compute dot-product similarity against the query vector. Fast enough for 5,000–10,000 photos.
pure Dart, dart:isolate
on-device MVP
sqlite-vec / ObjectBox (scale)
Drop-in upgrade when gallery exceeds 10,000 photos. sqlite-vec adds ANN vector search as a SQLite extension. ObjectBox has native vector support. Same API surface, faster at scale.
sqlite_vec or objectbox_flutter
on-device post-MVP
SQLite FTS5 (BM25)
Keyword search over ML Kit labels and cloud captions stored as text. Result scores fused with CLIP cosine scores at 0.3 weight. Built into SQLite — no extra library.
drift FTS5 extension
on-device
Score fusion
Combines CLIP dense score and BM25 sparse score: Final = 0.7 × clip_score + 0.3 × bm25_score. Both normalised to [0,1] before fusion. Written in pure Dart.
pure Dart
on-device
Database & storage local persistence
drift
Type-safe ORM over SQLite for Flutter. Defines all 14 tables as Dart classes. Generates DAOs, migrations, and reactive streams.
drift + drift_flutter
SQLite 3
Underlying DB engine. Zero server setup. Handles the 14-table schema: photos, embeddings (512-dim BLOB), labels, events, places, captions, kv_settings, etc.
sqlite3_flutter_libs
shared_preferences
Lightweight key-value store for app settings: theme, consent flags, indexing config, last-indexed folder path.
shared_preferences
Gallery & media access reading photos from the device
photo_manager
Reads the Android (and iOS) camera roll. Lists albums, fetches photo assets with metadata, loads thumbnails and full-size images. Core of M1.
photo_manager
permission_handler
Requests READ_MEDIA_IMAGES (Android 13+) and READ_EXTERNAL_STORAGE (Android 12). Shows rationale dialog if denied. Required before photo_manager can load anything.
permission_handler
EXIF extraction
Reads GPS coordinates, date taken, camera model, and dimensions from photo EXIF metadata at index time. GPS lat/lng stored in the places table for map view.
exif (pub.dev)
image / flutter_image_compress
Resizes photos to 224×224px before feeding into CLIP (required input size). Compression reduces memory during batch indexing.
flutter_image_compress
Maps & location GPS photo view
flutter_map
Leaflet.js-inspired open-source map widget for Flutter. No API key needed. Renders GPS photo pins over OpenStreetMap tiles.
flutter_map
OpenStreetMap tiles
Free map tile provider. Works offline if tiles are cached. No account or billing required — aligns with privacy-first principle.
tile.openstreetmap.org
Nominatim (opt-in)
OSM reverse geocoding API. Converts GPS coords to human-readable place names (e.g. "Baga Beach, Goa"). Sends coordinates only, never photos.
http → nominatim.openstreetmap.org
Clustering & timeline grouping photos into events
DBSCAN (Dart port)
Density-based clustering on photo timestamps. Groups nearby-in-time photos into "events" without needing to specify how many clusters. Written in pure Dart, runs in an isolate.
pure Dart implementation
on-device
Groq API — smart event names
Sends event caption summaries (text only, no photos) to llama-3.1-8b-instant on Groq. Returns human-readable event label: "Goa trip — Dec 2023". Cached locally.
http → api.groq.com
cloud opt-in
UI & navigation screens, routing, components
Material 3
Flutter's built-in Material 3 design system. Dynamic colour theming, modern components, adaptive layouts.
flutter/material.dart
go_router
Declarative routing. Handles deep links, nested navigation, and the bottom tab shell without boilerplate.
go_router
cached_network_image
For cloud caption API responses that return image thumbnails. Local thumbnails use photo_manager directly.
cached_network_image
flutter_staggered_grid_view
Masonry/staggered grid layout for the photo results screen. Handles variable-height thumbnails without fixed-size cells.
flutter_staggered_grid_view
Hero animation
Flutter built-in. Animates photo from grid thumbnail to full-screen viewer with a smooth shared-element transition.
flutter/widgets.dart
shimmer
Loading skeleton placeholders shown in the photo grid while indexing is in progress or thumbnails are loading.
shimmer
Background processing indexing without freezing the UI
Dart Isolates
All heavy work runs in a separate isolate: CLIP embedding, cosine search computation, DBSCAN clustering, thumbnail decoding. UI thread never blocks.
dart:isolate
WorkManager
Android background task scheduler. Runs incremental re-indexing when the app is in the background or phone is charging. Survives app restarts.
workmanager
Optional cloud backend FastAPI — consent-gated, never breaks local search
FastAPI + Pydantic v2
Python backend for optional cloud features. Thin relay layer — validates requests, calls AI APIs, returns results. No user data stored server-side.
fastapi + uvicorn
cloud
Groq API
llama-3.1-8b-instant for conversational search assistant and event naming. Text queries only — no photos ever sent. Free tier: 30 req/min.
groq-python
cloud

GPT-4o Vision or Gemini 1.5 Flash for photo captioning. Only triggered by explicit user consent per photo. Result cached locally after first call.
openai / google-generativeai
